# AWS Projects

Hands-on AWS projects built to learn the services behind the AWS Certified Solutions Architect – Associate and AWS Certified Cloud Practitioner exams. Each project is built in the AWS console, documented in its own README, and then torn down to avoid charges.

## Projects

## Conventions

- Each project lives in its own folder with a README covering architecture, steps, verification, issues, and teardown.
- Nothing is left running. Every project ends with a teardown section.
