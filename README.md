# AWS Projects

Hands-on AWS projects built to learn the services behind the AWS Certified Solutions Architect – Associate and AWS Certified Cloud Practitioner exams. Each project has its own README covering architecture, build steps, verification, and teardown, so nothing is left running after the project ends.

Projects are listed from easiest to hardest.

## Projects

| # | Project | Services | Status |
|---|---------|----------|--------|
| 1 | [AWS IAM access control](project-01-iam-access-control/) | EC2, IAM | Built, tested, torn down |
| 2 | [Static site on private S3 + CloudFront](project-02-static-site-s3-cloudfront/) | S3, CloudFront, OAC | Deployed, verified, torn down |
| 3 | [AWS Cloud Infrastructure](project-03-aws-cloud-infrastructure/) | VPC, EC2, S3, IAM, Systems Manager | Built, checked, torn down |
| 4 | [Serverless automation](project-04-serverless-automation/) | S3, Lambda, CloudWatch | Built, tested, torn down |
| 5 | [Serverless REST API](project-05-serverless-api/) | API Gateway, Lambda, DynamoDB, Cognito | Deployed, verified, torn down |

## Conventions

- Each project lives in its own folder with a README covering architecture, build steps, verification, teardown, and the concepts practiced.
- Every project ends with a teardown section so nothing keeps running and costing money.
